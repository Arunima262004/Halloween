 # Project Overview 

This project is an interactive Halloween Visitors Analysis Dashboard created using Tableau. The dashboard analyzes visitor data across different years to identify trends, variations, and future visitor patterns.

 # Dashboard Features

- Interactive data visualizations
- Year-wise visitor analysis
- Visitor trend analysis over time
- Comparison of actual and estimated visitors
- Forecasting of future visitor numbers
- Easy-to-understand dashboard design

# Project Objective

The main objective of this project is to analyze Halloween visitor data, understand yearly trends and variations, and use forecasting techniques to estimate future visitor numbers.

 # Key Insights

- Visitor numbers vary across different years.
- The dashboard identifies the highest and lowest visitor periods.
- Year-wise analysis helps identify changes in visitor patterns.
- The visitor trend shows how attendance changes over time.
- Forecasting provides an estimate of future visitor numbers.
